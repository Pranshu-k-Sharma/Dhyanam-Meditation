# Futuristic Meditation Website

A calm, immersive meditation landing experience built with React + Vite, Tailwind CSS, and Framer Motion.

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start dev server:

```bash
npm run dev
```

3. Build production bundle:

```bash
npm run build
```

## Tech Stack

- React (Vite)
- Tailwind CSS
- Framer Motion
